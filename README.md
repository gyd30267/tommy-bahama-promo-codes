A few return edge cases that catch people off guard:

- **Gift with purchase orders:** if you return the items, you must send back the free gift to get a full refund to your original payment method — otherwise you get merchandise credit. If your returned order still clears the gift threshold, you can keep it.
- **Outlet stores:** all outlet sales are final. No refunds, no store credit — unworn, unwashed items in original packaging can be exchanged for equal or greater value at an outlet within 30 days, with receipt. Swimwear can't be returned or exchanged at outlets at all.
- **Cash back and returns:** because portal cash back is usually confirmed after the return window closes, a returned item's cash back comes out of the final amount — so the "stack" is real, but it's calculated on what you actually keep.
